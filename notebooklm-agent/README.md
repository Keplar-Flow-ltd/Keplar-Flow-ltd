# NotebookLM Agent

This agent integrates Google's NotebookLM into the Keplar Flow ecosystem, enabling ethical content synthesis and podcast generation from documents.

## Features

- **Ethical Source Scrubbing**: Automatically applies compliance protocols to all documents.
- **Podcast Generation**: Creates custom podcasts from uploaded sources.
- **Data Interoperability**: Seamless exchange between VS Code and NotebookLM workspaces.
- **Administrative Support**: Enhances reporting and documentation workflows.

## Sub-Agents

- **source-scrubber**: Handles ethical and legal compliance checks.
- **podcast-generator**: Manages podcast creation and customization.
- **data-exchanger**: Facilitates data transfer protocols.

## Usage

Invoke the agent for content-related tasks requiring AI synthesis while maintaining ethical standards.

## Compliance

All operations follow the notebooklm-scrubbing-protocol.md and Keplar Flow's decent work principles.
